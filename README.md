# Superposition Theorem - Dual Circuit Bench Laboratory

An interactive browser-based virtual laboratory simulator for verifying the Superposition Theorem across both Voltage Source (Thevenin) and Current Source (Norton) network configurations, built for electrical engineering students.

## Created By
* **Dr. Nitin Phadkule**
* **Department of Electrical & Telecommunication Engineering**
* **Govt. College of Engineering, Chh. Sambhajinagar**

## Key Features
- **Dual Source Modes:** Instantly toggle between dual voltage sources ($V_1, V_2$) and dual current sources ($I_1, I_2$).
- **Flexible Measurement:** Switch between measuring Load Current ($I_L$) and Load Voltage ($V_L$).
- **Hardware Bench Aesthetics:** Realistic toggle switches with active LED indicators, regulated sliders, and a digital multimeter (DMM) readout.
- **Printable HTML Lab Reports:** Automatic generation of standalone lab reports pre-filled with observation tables, dynamic circuit diagrams, and interactive viva voce response fields.

## System Requirements
- Runs locally or online in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- **Zero Installation Required:** Pure HTML5, CSS3, and JavaScript utilizing the HTML5 Canvas API.

## Usage
1. Download or clone the repository.
2. Open `superposition_theorem_lab.html` directly in your browser.
